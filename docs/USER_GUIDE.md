# 用户指南

## 欢迎使用 wuhan-life

wuhan-life是一个探索武汉夜生活的平台，帮助您发现最地道的夜市美食和最美的骑行路线。

---

## 功能介绍

### 1. 夜市探索

**功能：** 浏览武汉各大夜市，查看美食推荐

**特色：**
- 10+ 热门夜市
- 评分排序
- 区域筛选
- 美食推荐

**使用方法：**
1. 访问首页
2. 点击"夜市探索"卡片
3. 浏览夜市列表
4. 点击夜市查看详情

---

### 2. 跑山路线

**功能：** 探索武汉周边骑行路线，享受自然风光

**特色：**
- 17+ 精选路线
- 难度分级
- 距离时长
- 路点导航

**使用方法：**
1. 访问首页
2. 点击"跑山路线"卡片
3. 浏览路线列表
4. 点击路线查看详情

---

### 3. 搜索功能

**功能：** 快速搜索夜市或路线

**使用方法：**
1. 在首页搜索框输入关键词
2. 点击"搜索"按钮
3. 查看搜索结果

**搜索技巧：**
- 支持中英文搜索
- 可搜索名称、地址、描述
- 支持模糊匹配

---

### 4. 筛选排序

**功能：** 按条件筛选和排序结果

**筛选选项：**
- 评分范围（0-100）
- 区域（夜市）

**排序选项：**
- 评分（默认）
- 创建时间
- 名称
- 难度（跑山路线）

**使用方法：**
1. 进入列表页面
2. 使用顶部筛选器
3. 选择排序方式
4. 查看结果

---

## 常见问题

### Q1：如何搜索夜市？

**A：**
1. 在首页搜索框输入关键词
2. 点击"搜索"按钮
3. 系统会搜索名称、地址、描述

**示例：**
- 搜索"户部巷" - 找到户部巷夜市
- 搜索"武昌" - 找到武昌区的夜市

---

### Q2：如何筛选高评分夜市？

**A：**
1. 进入夜市列表页
2. 使用"评分范围"筛选器
3. 设置最低评分（如10分）
4. 查看筛选结果

---

### Q3：跑山路线难度如何划分？

**A：**
- **easy（简单）：** 适合新手，距离<20km，时长<2h
- **medium（中等）：** 需要一定经验，距离20-40km，时长2-4h
- **hard（困难）：** 适合资深骑行者，距离>40km，时长>4h

---

### Q4：页面加载缓慢怎么办？

**A：**
1. 检查网络连接
2. 清除浏览器缓存
3. 刷新页面
4. 尝试其他浏览器

---

### Q5：数据多久更新一次？

**A：**
- 夜市数据：每周更新
- 跑山路线：每周更新
- 用户评价：实时更新

## 注意事项

### 使用建议

1. **网络环境：** 建议使用稳定的网络连接
2. **浏览器：** 推荐使用Chrome浏览器
3. **屏幕：** 支持桌面和移动设备
4. **缓存：** 建议启用浏览器缓存

---

### 数据说明

1. **评分：** 基于小红书点赞数计算
2. **距离：** 跑山路线的骑行距离
3. **时长：** 预计骑行时间
4. **更新：** 数据每周从小红书爬取

---

### 隐私保护

1. **无需登录：** 无需注册即可使用
2. **不收集数据：** 不收集个人信息
3. **Cookie：** 仅用于功能优化
4. **安全：** 使用HTTPS加密
