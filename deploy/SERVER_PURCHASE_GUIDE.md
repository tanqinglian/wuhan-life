# 服务器购买指南 - 2核2G配置

## 一、腾讯云轻量应用服务器

### 1. 购买步骤

**访问地址：** https://cloud.tencent.com/product/lighthouse

**选择配置：**
- CPU：2核
- 内存：2GB
- 带宽：4Mbps
- 存储：50GB SSD
- 地域：武汉/上海（就近选择）
- 镜像：Ubuntu 20.04

**价格：**
- 新用户：62元/月
- 续费：112元/月
- 建议：购买1年（更优惠）

**购买流程：**
1. 注册/登录腾讯云
2. 进入轻量应用服务器页面
3. 选择配置：2核2G，带宽4M
4. 选择地域：武汉/上海
5. 选择镜像：Ubuntu 20.04
6. 选择时长：1年
7. 确认订单并支付

## 三、购买后配置

### 1. 获取服务器信息
- 公网IP地址
- root密码（或SSH密钥）

### 2. 连接服务器

**Windows（PowerShell）：**
```powershell
ssh root@你的服务器IP
```

**Windows（SSH工具）：**
- Putty：https://www.putty.org/
- Xshell：https://www.xshell.com/
- Termius：https://termius.com/

### 3. 首次登录后执行

```bash
# 更新系统
apt update && apt upgrade -y

# 设置时区
timedatectl set-timezone Asia/Shanghai

# 查看系统信息
free -h
df -h
```

## 五、常见问题

**Q: 选择腾讯云还是阿里云？**
A: 新用户推荐腾讯云（62元/月），带宽更大（4M vs 3M）

**Q: 地域选择哪里？**
A: 选择离用户最近的地域，武汉/上海优先

**Q: 需要购买域名吗？**
A: 不是必须，可以用IP访问。但建议购买域名（10-50元/年）

**Q: 需要备案吗？**
A: 如果使用域名，需要备案（15-20天）。IP访问不需要备案
